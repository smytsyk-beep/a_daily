# Команда /continue для продолжения онбординга

## Проблема

При прерывании онбординга (например, пользователь вводит /today вместо того, чтобы поделиться локацией) бот говорит использовать /start для продолжения. Но /start не продолжает с места остановки, а проверяет наличие данных и может начать заново.

## Решение

Добавлена новая команда /continue, которая:
1. Проверяет текущее состояние онбординга (onboarding_state)
2. Продолжает с того шага, где остановились
3. Обрабатывает все возможные состояния онбординга

## Поддерживаемые состояния

- STATE_AGE_GATE - показывает age gate
- STATE_ASK_BIRTH_DATE - запрашивает дату рождения
- STATE_ASK_BIRTH_TIME - запрашивает время рождения
- STATE_ASK_BIRTH_PLACE - запрашивает место рождения
- STATE_ASK_TIMEZONE_LOCATION - запрашивает геолокацию для timezone (критично!)
- STATE_ASK_PREFS_TOPICS - запрашивает интересы
- STATE_ASK_PREFS_DELIVERY - запрашивает длину дайджеста

## Сценарий использования

1. Пользователь начинает онбординг с /start
2. На этапе "поделиться локацией" вводит другую команду (например /today)
3. Бот отвечает: "Сначала нужно завершить настройку профиля. Используй /continue для продолжения онбординга."
4. Пользователь вводит /continue
5. Бот продолжает с того же шага (запрос локации)

## Изменённые файлы

1. src/app/routes_telegram.py
   - Добавлен handler для команды /continue
   - Обработка всех состояний онбординга

2. src/app/locales/ru.json, en.json, es.json
   - Обновлено сообщение "onboarding.incomplete" (ссылается на /continue)
   - Добавлен раздел "continue" с сообщениями:
     - already_complete - онбординг уже завершён
     - unknown_state - неизвестное состояние
   - Обновлены help.basic и help.full с упоминанием /continue

## Отличие от /start

/start:
- Всегда начинает с проверки age_gate
- Если нет birth_data, запрашивает с начала
- Подходит для нового пользователя или полного перезапуска

/continue:
- Продолжает с текущего состояния онбординга
- Не сбрасывает уже введённые данные
- Подходит для возобновления прерванного онбординга

## Тестирование

Запустите скрипт:
python scripts/test_continue_command.py

Или протестируйте вручную:
1. Войдите в бот с новым пользователем
2. Пройдите онбординг до этапа "поделиться локацией"
3. Вместо этого введите /today
4. Бот предложит использовать /continue
5. Введите /continue
6. Бот должен снова показать запрос локации
7. Завершите онбординг

## Важно

Команда /continue работает только если есть активное состояние онбординга.
Если онбординг уже завершён (state = STATE_COMPLETE или отсутствует),
бот сообщит: "Онбординг уже завершён! ✅"
