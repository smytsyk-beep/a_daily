# Fix v2: Location Handling + Keyboard Removal + /today Check

## Обнаруженные проблемы после первого фикса

1. **Кнопки геолокации не исчезают** после перехода на следующий шаг
2. **Команда `/today` падает с ошибкой** на строке 1382
3. **Часовой пояс записывается** в таблицу, но что-то идёт не так

## Исправления

### 1. Корректное удаление клавиатуры

**Проблема:** Отправлялось два сообщения подряд:
1. Первое с `reply_markup={"remove_keyboard": True}`
2. Второе без `reply_markup`

Telegram убирает клавиатуру только если **последнее** сообщение содержит `remove_keyboard`.

**Решение:** Объединить сообщения в одно:

```python
# БЫЛО (строки 802-814):
send_message(chat_id, tr(lang, "tg.onboarding.timezone_saved", ...), 
             reply_markup={"remove_keyboard": True})
send_message(chat_id, tr(lang, "tg.onboarding.prefs_topics_prompt"))

# СТАЛО (строка 807):
send_message(
    chat_id,
    tr(lang, "tg.onboarding.timezone_saved", timezone=timezone_str) + "\n\n" + 
    tr(lang, "tg.onboarding.prefs_topics_prompt"),
    reply_markup={"remove_keyboard": True}
)
```

Аналогично для fallback случая (строка 821-830).

### 2. Проверка завершённости онбординга для /today

**Проблема:** `/today` пытался работать даже если:
- Онбординг не завершён
- У пользователя нет `timezone`
- Нет birth_data

**Решение:** Добавлены проверки перед выполнением команды (строки 1344-1361):

```python
if text.startswith("/today"):
    # Проверка завершённости онбординга
    onboarding_state = _get_onboarding_state(user)
    if onboarding_state and onboarding_state != STATE_COMPLETE:
        send_message(chat_id, tr(lang, "tg.onboarding.incomplete"))
        return {"status": "ok"}
    
    # Проверка наличия timezone
    if not user.timezone:
        send_message(chat_id, tr(lang, "tg.onboarding.incomplete"))
        return {"status": "ok"}
    
    # ... дальше rate limit и логика digest
```

### 3. Локализация для незавершённого онбординга

Добавлен ключ `tg.onboarding.incomplete` во все локали:

**ru.json:**

**en.json:**

## Тестирование

1. **Новый онбординг с location:**
   - Пройти онбординг
   - На шаге timezone поделиться геолокацией
   - ✅ Проверить, что клавиатура исчезла
   - ✅ Проверить, что `/today` работает

2. **Новый онбординг с пропуском:**
   - Пройти онбординг
   - На шаге timezone нажать "Пропустить"
   - ✅ Проверить, что клавиатура исчезла
   - ✅ Проверить, что timezone взят из birth_place
   - ✅ Проверить, что `/today` работает

3. **Незавершённый онбординг:**
   - Начать онбординг
   - НЕ завершать его
   - Отправить `/today`
   - ✅ Проверить, что бот просит завершить профиль

4. **Запоздалый клик по location:**
   - Завершить онбординг
   - Нажать старую кнопку "📍 Поделиться локацией" (если она осталась)
   - ✅ Проверить, что бот отправляет `tg.location.unexpected`
