# Fix v3: Russian Language Support for Geocoding

## Проблема

Пользователь обнаружил, что команда `/today` не работает, если он вводит место рождения на русском языке (например, "Киев, Украина" вместо "Kyiv, Ukraine").

### Причина

Геокодер (`geocode_place` в `services/geo.py` и `resolve_place_to_geo` в `birth_geo_service.py`) содержал только английские названия городов и стран в справочниках `CITY_DB` и `COUNTRY_DB`.

Когда пользователь вводил "Киев, Украина":
1. Геокодер не находил совпадений
2. Возвращал `None`
3. `birth_data` сохранялась без координат (`lat=None`, `lon=None`)
4. `/today` не мог вычислить натальную карту и падал с ошибкой

## Решение

Добавлена поддержка русского (и украинского) языка для наиболее распространённых городов и стран.

### 1. Расширение справочников в `services/geo.py`

Добавлены русские названия:

**COUNTRY_DB:**
- Украина → "украина": `GeoResult(50.4501, 30.5234, "Kyiv, Ukraine")`
- Россия → "россия": `GeoResult(55.7558, 37.6173, "Moscow, Russia")`
- США → "сша": `GeoResult(40.7128, -74.0060, "New York, USA")`
- Беларусь → "беларусь": `GeoResult(53.9045, 27.5615, "Minsk, Belarus")`
- Молдова → "молдова": `GeoResult(47.0105, 28.8638, "Chisinau, Moldova")`
- Казахстан → "казахстан": `GeoResult(43.2220, 76.8512, "Almaty, Kazakhstan")`
- Турция → "турция": `GeoResult(41.0082, 28.9784, "Istanbul, Turkey")`
- Испания → "испания": `GeoResult(40.4168, -3.7038, "Madrid, Spain")`

**CITY_DB (украинские города):**
- "киев украина", "київ україна" → Киев
- "харьков украина", "харків україна" → Харьков
- "одесса украина", "одеса україна" → Одесса
- "львов украина", "львів україна" → Львов

**CITY_DB (другие города):**
- "москва россия", "санкт-петербург россия", "питер россия"
- "нью-йорк сша", "лос-анджелес сша"
- "минск беларусь"
- "кишинев молдова"
- "стамбул турция"
- "мадрид испания", "барселона испания"
- "лондон великобритания"
- "алматы казахстан"

### 2. Синхронизация `birth_geo_service.py`

Обновлены справочники `CITY_DB` и `COUNTRY_DB` с теми же русскими названиями для консистентности.

### 3. Обновление подсказок в локализациях

## Расширение справочника

Если нужно добавить новый город:

1. Найдите координаты на maps.google.com
2. Определите IANA timezone (Europe/Moscow, America/New_York и т.д.)
3. Добавьте в оба файла:

**services/geo.py:**
```python
CITY_DB = {
    ...
    "новый город страна": GeoResult(lat, lon, "Display Name"),
}
```

**birth_geo_service.py:**
```python
CITY_DB = {
    ...
    "новый город страна": GeoResult(lat, lon, "Timezone/IANA"),
}
```
