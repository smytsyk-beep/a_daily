# Исправление циклической ошибки callback_query

## Проблема

При нажатии кнопки "Время рождения" в `/settings` бот постоянно отправлял сообщение:
> ⚠️ Изменение времени рождения пересчитает твою натальную карту.
>
> Отправь новое время рождения в формате HH:MM или напиши Не знаю.

Сообщение приходило циклично, даже после указания нового времени.

## Причина

Telegram Bot API требует вызов метода `answerCallbackQuery` для подтверждения обработки callback_query. Без этого:
1. Telegram не получает подтверждение обработки
2. Telegram повторно отправляет callback_query
3. Наш webhook снова обрабатывает его и отправляет сообщение
4. Цикл повторяется

## Решение

### 1. Добавлена функция `answer_callback_query` в `telegram_client.py`

Функция отправляет подтверждение в Telegram API о том, что callback_query обработан.

### 2. Извлечение `callback_query_id` из update

В функции `_extract_message()` добавлено извлечение ID callback_query.

### 3. Вызов `answer_callback_query` в webhook handler

В начале обработки callback_data добавлен обязательный вызов подтверждения.

## Изменённые файлы

1. `src/app/telegram_client.py` - добавлена функция `answer_callback_query()`
2. `src/app/routes_telegram.py` - интеграция вызова во все callback handlers

## Тестирование

После применения исправления:
1. Нажмите кнопку "Время рождения" в `/settings`
2. Должно прийти **одно** сообщение с запросом времени
3. Циклические повторы должны прекратиться
4. После ввода времени должно произойти обновление данных

## Важно

Это исправление применяется ко **всем** callback_query в боте.
